# Message Automations

Answer people who message your Telegram bot automatically, work every conversation from one shared inbox, and send broadcasts to the contacts you choose.

Inspired by https://manychat.com

Built with [oss.new](https://oss.new) for [EveryApp](https://github.com/every-app/every-app).

## Features

- Connect a Telegram bot and see whether it and its webhook are working.
- Build automations that greet new contacts, answer keywords or reply when nothing else matches, with messages, link buttons, questions, waits and tags.
- Keep contacts with tags, custom fields, collected emails and phone numbers, and subscription state.
- Read and reply to every conversation in a shared inbox, with stars, assignees and done.
- Send or schedule broadcasts to everyone or to contacts with chosen tags.
- Try your automations in a private preview conversation without a bot.

Left out: Instagram, Messenger, WhatsApp, TikTok, SMS and email channels; AI replies; templates; integrations and analytics beyond counts; plans and billing; a mobile app; and accounts and sign-in, which your Gateway handles.

## Setup

```sh
pnpm install
pnpm dev             # run locally behind the EveryApp launcher
pnpm test            # unit tests
pnpm run deploy      # deploy to your Cloudflare account through your Gateway
```

The release checks in `checks/` run against a packaged build with the oss.new runtime.

What the app reads:

- `TELEGRAM_BOT_TOKEN` (optional, Telegram bot feature): your bot's token from @BotFather. Without it the channel shows as off and nothing is sent; the preview still works. After setting it, an admin opens Settings and presses Register webhook.
- `TELEGRAM_WEBHOOK_SECRET` (generated by the deploy): checked on every webhook call so only Telegram can post messages.
- `TELEGRAM_API_URL` (setting, default `https://api.telegram.org`): the Bot API server to use.

## Limitations

- Telegram only, and only private chats with the bot; group messages are ignored.
- A manual reply pauses automations for that contact for 30 minutes, or until someone presses Resume.
- Waits and scheduled broadcasts run on a one-minute cron, so they can be up to a minute late.
- Assignees are the members who have opened the app at least once.
- Sending through a real bot and a deployed Gateway is not covered by the local checks, which use a stand-in for the Bot API.
